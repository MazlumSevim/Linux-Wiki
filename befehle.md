# 🧠 Linux-Befehle

## 📂 Navigation
pwd        # aktuelles Verzeichnis
ls         # Dateien anzeigen
ls -la     # detailliert
cd /home   # wechseln
cd ..      # zurück

## 📄 Dateien & Ordner
touch datei.txt      # Datei erstellen
mkdir ordner         # Ordner erstellen
rm datei.txt         # Datei löschen
rm -r ordner         # Ordner löschen

## 📖 Hilfe
man ls               # Handbuch
