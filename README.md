# 🐧 Linux-Wiki

Ein gemeinsames Lernprojekt über Linux-Befehle, Benutzerverwaltung, Netzwerke und Bash-Skripte.

Dieses Wiki dient dazu, wichtige Linux-Grundlagen strukturiert zu dokumentieren und praktisch zu lernen.

---

## 📚 Inhalte

- Befehle und Grundlagen
- Benutzerverwaltung
- Netzwerk-Kommandos
- Bash-Skripte

---

## 📁 Projektstruktur


linux-wiki/
├── README.md
├── befehle.md
├── benutzer.md
├── netzwerk.md
└── skripte.md


---

## 🎯 Lernziele

- Linux-Befehle verstehen und anwenden
- Arbeiten mit dem Terminal
- Grundlagen von Bash-Skripten
- Netzwerkdiagnose unter Linux
- Benutzer und Rechte verwalten

---

## 🚀 Ziel des Projekts

Dieses Projekt soll zeigen, wie man mit Git und GitHub gemeinsam Dokumentationen erstellt und versioniert.
